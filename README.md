# 💰 FinZen

**FinZen** es una aplicación web para la gestión de finanzas personales que permite a los usuarios controlar sus ingresos, gastos, cuentas, presupuestos y objetivos de ahorro desde una interfaz intuitiva y moderna.

Este proyecto ha sido desarrollado con fines de aprendizaje y como parte de mi portfolio como desarrollador web.

---

## 📌 Características

- 🔐 Sistema de registro e inicio de sesión.
- 📊 Dashboard con resumen financiero.
- 💸 Gestión de ingresos y gastos.
- 🏦 Administración de múltiples cuentas.
- 🎯 Creación de objetivos de ahorro.
- 📅 Presupuestos mensuales.
- 📱 Diseño responsive.
- 🌙 Modo oscuro *(próximamente)*.
- 📈 Estadísticas y gráficas *(próximamente)*.

## ⚙️ Instalación

Clona el repositorio:

```bash
git clone https://github.com/TU_USUARIO/finzen.git
```

Entra en el directorio:

```bash
cd finzen
```

Abre el proyecto con Visual Studio Code.

Si el proyecto es únicamente HTML, CSS y JavaScript, puedes ejecutarlo con **Live Server**.
